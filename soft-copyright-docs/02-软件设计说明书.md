# 1Claw 多智能体平台软件

## 软件设计说明书

### V1.0

---

### 1. 概述

#### 1.1 项目背景

1Claw 是一套用于管理多 AI 智能体实时通信的平台软件。用户可通过手机、电脑等终端同时连接多个不同角色的 AI 智能体，以 WebSocket 长连接的方式进行实时对话。系统由 Go 语言编写的服务端网关和 Flutter 编写的跨平台客户端组成。

#### 1.2 设计目标

- 支持多个 AI 智能体角色同时在线运行
- 低延迟、实时双向通信
- 跨平台客户端覆盖（Android/iOS/macOS/Windows/Linux）
- 后台保活、断线自动重连
- 轻量化部署（500MB 内存即可运行）

### 3. 模块设计

#### 3.1 服务端模块

##### 3.1.1 WebSocket Hub（连接枢纽）

**文件位置**：`internal/ws/hub.go`、`internal/ws/client.go`

功能描述：
- 统一管理所有 WebSocket 客户端连接
- 消息路由：根据 `profile_id` 将消息路由到对应智能体
- 连接状态管理：注册/注销客户端
- 广播状态更新：向所有已连接客户端推送角色状态变更

核心数据结构：

```go
// Hub 管理所有活跃 WebSocket 客户端连接
type Hub struct {
    clients    map[*Client]bool
    broadcast  chan []byte
    register   chan *Client
    unregister chan *Client
}

// Client 代表一个 WebSocket 连接
type Client struct {
    hub  *Hub
    conn *websocket.Conn
    send chan []byte
}
```

##### 3.1.2 Agent Bridge（智能体桥接）

**文件位置**：`internal/agent/bridge.go`、`internal/agent/hermes_bridge.go`

功能描述：
- 定义智能体提供者接口（`Provider interface{}`）
- MockBridge：调试模式，回显模式
- HermesBridge：生产模式，通过子进程方式调用 Hermes AI Agent
- JSON-over-stdin/stdout 进程间通信协议

核心接口：

```go
// Provider 定义了智能体后端的接口
type Provider interface {
    Start(context.Context) error
    Stop() error
    Chat(profileID, content, msgID string) (*Model.ChatResponse, error)
    GetProfiles() []*Model.Profile
    StartProfile(profileID string) error
    Status() *Model.ServerStatus
}
```

### 6. 智能体初始化机制

#### 6.1 双阶段初始化

为优化启动速度，采用懒加载的双阶段策略：

1. **Phase 1（即时）**：服务端启动后，所有角色立即上线并以 Echo 模式运作（镜像反射用户输入），启动时间 < 5 秒
2. **Phase 2（按需）**：用户首次点击角色卡片或发送消息时，后台线程在 10-60 秒内完成真实 AI 引擎加载，后续对话转由真实 AI 处理

```
用户点开角色
  → 发送 start_profile 指令
  → 服务端转发至 Python Bridge
  → Bridge 返回 agent_starting 状态
  → UI 展示「启动中...」
  → 后台线程初始化 AIAgent
  → 成功后发送 agent_ready
  → UI 更新为「在线」
```

#### 6.2 环境变量与配置加载顺序

1. `~/.hermes/.env` — 全局 API 密钥
2. `/etc/environment` — 系统环境变量
3. `~/.hermes/profiles/<name>/.env` — 角色级环境变量
4. `~/.hermes/profiles/<name>/config.yaml` — 角色配置

### 7. 安全设计

#### 7.1 通信安全
- WebSocket 支持 WSS（TLS 加密）
- 支持网络隔离部署

#### 7.2 会话安全
- 各智能体角色独立会话
- 角色间数据隔离
- API 密钥仅存于服务端

#### 7.3 错误处理
- 全局异常捕获（Flutter）
- 崩溃日志本地存储
- 服务端优雅关闭（信号处理）
