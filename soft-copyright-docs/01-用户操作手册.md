# 1Claw 多智能体平台软件

## 用户操作手册

### V1.0

---

### 1. 软件概述

1Claw 是一款多智能体（Multi-Agent）通信平台软件，由 Flutter 移动端/桌面端应用与 Go 语言服务端组成。用户可通过手机、平板或电脑同时接入多个 AI 智能体角色，以 WebSocket 长连接方式进行实时对话，实现多角色同时在线、随时切换、实时响应的智能交互体验。

本软件适用于个人用户、开发者团队及企业用户，用于构建多角色 AI 助手集群，实现高效的人机协作。

### 3. 安装部署

#### 3.1 服务端部署

**方式一：直接运行**

```bash
# 克隆服务端代码
git clone <repository_url>/1claw-server.git
cd 1claw-server

# 编译
make build

# 运行（自动检测 Hermes AI 引擎）
./1claw-server

# 调试模式（Mock 模式，无需 API 密钥）
./1claw-server --mock
```

**方式二：Docker 部署**

```bash
docker build -t 1claw-server .
docker run -d -p 8080:8080 --name 1claw-server 1claw-server
```

**方式三：配置文件自定义**

编辑 `config.yaml` 文件可配置以下参数：

```yaml
server:
  host: "0.0.0.0"
  port: 8080
websocket:
  ping_interval: 30s
  write_timeout: 10s
profiles:
  - id: "assistant"
    name: "AI Assistant"
    emoji: "🤖"
    description: "General-purpose AI assistant"
    color: "#0078D7"
  - id: "writer"
    name: "Creative Writer"
    emoji: "✍️"
    description: "Creative writing specialist"
    color: "#7B1FA2"
```

#### 3.2 客户端安装

Android 用户直接从 APK 文件安装，iOS 用户通过 TestFlight 安装，桌面端用户：

```bash
# Linux 桌面端
cd 1claw-app
flutter run -d linux

# macOS 桌面端
flutter run -d macos

# Windows 桌面端
flutter run -d windows
```

### 4. 首次使用

#### 4.1 启动服务端

在服务器上执行以下命令启动 1Claw 服务端：

```bash
cd /path/to/1claw-server
./1claw-server
```

服务端启动后将自动扫描 Hermes Agent 配置目录（`~/.hermes/profiles/`），发现所有可用智能体角色，并在控制台输出启动日志：

```
[1claw-server] Starting WebSocket server on :8080
[1claw-server] Discovered 5 agent profiles
[1claw-server] WebSocket hub ready
```

#### 4.2 连接客户端

打开 1Claw 客户端应用：

1. 首次启动时将弹出服务器配置界面
2. 输入服务端 WebSocket 地址（默认 `ws://<服务器IP>:8080/ws`）
3. 点击「连接」按钮
4. 连接成功后，主页将显示所有可用智能体角色卡片

#### 4.3 主界面概览

主界面采用 Metro 风格卡片式布局，展示所有智能体角色：

- **连接状态指示器**：顶部显示当前 WebSocket 连接状态（绿=已连接 / 红=断开）
- **角色卡片列表**：每个卡片包含角色头像（Emoji）、名称、描述、在线状态
- **筛选/排序栏**：支持按名称搜索、按时间/字母排序
- **刷新按钮**：手动刷新角色状态
- **设置按钮**：进入设置页面

### 5. 功能使用指南

#### 5.1 智能体角色管理

**查看角色状态**

每个智能体卡片显示以下信息：
- 角色头像（Emoji 表情符号）
- 角色名称
- 角色职责描述
- 在线状态指示（绿色=在线 / 灰色=离线）
- 工作状态（工作中/空闲/启动中）
- 待处理任务数

**切换角色**

点击任意角色卡片即可切换到该智能体的对话界面。

**筛选角色**

在搜索栏输入关键词，实时筛选匹配的角色卡片。

#### 5.2 对话功能

**发送消息**

1. 点击目标角色卡片进入对话界面
2. 在底部输入框输入消息内容
3. 点击发送按钮或按 Enter 键发送
4. 消息通过 WebSocket 实时发送到服务器，AI 智能体实时回复

**对话界面组成**

- **头部区域**：当前角色名称、Emoji 头像、在线状态
- **消息列表**：按时间顺序展示对话历史（用户消息 + AI 回复）
- **消息气泡**：用户消息靠右显示（蓝色），AI 回复靠左显示（灰色）
- **输入区域**：文本输入框 + 发送按钮 + 附件按钮

**功能菜单**

在对话界面点击右上角菜单按钮，可执行以下操作：
- 清除当前对话历史
- 查看角色详情信息
- 切换回主界面

#### 5.3 多角色同时在线

1Claw 的核心特色是支持多个 AI 智能体**同时在线运行**：

- 服务端启动后立即加载所有已配置的角色
- 每个角色独立维护会话上下文和记忆
- 切换角色时无需等待加载，即时响应
- 角色之间互不干扰，各自独立处理任务

**双阶段初始化机制**

```
首次启动 → 所有角色快速上线（Echo 模式，< 5秒）
                    ↓
用户首次对话某角色 → 后台启动真实 AI 引擎
                    ↓
   后续对话 → 真实 AI 智能体实时回复
```

#### 5.4 后台保活

Android 客户端支持后台常驻保活：

- 利用 `flutter_background_service` 实现前台服务
- 锁屏、切后台后依然保持 WebSocket 连接
- 断线自动重连（两阶段重连策略）
- 收到新消息时通过系统通知栏推送提醒

#### 5.5 主题设置

应用支持明/暗双主题：

- **浅色模式**：白色背景，适合日间使用
- **深色模式**：深色背景，适合夜间使用
  - 减少屏幕亮度对眼睛的刺激
  - 节省 OLED 屏幕电量

在设置页面中可切换主题模式。

#### 5.6 字体设置

支持自定义界面字体：
- 在设置页面中浏览系统已安装字体
- 选择喜欢的字体应用到整个界面
- 查看字体预览效果

#### 5.7 服务器配置

在设置页面可配置以下连接参数：
- WebSocket 连接地址
- REST API 地址
- 配置保存后自动生效

### 6. API 接口说明

#### 6.1 REST API

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | `/health` | 健康检查 |
| GET | `/api/status` | 服务器状态 + 角色状态 |
| GET | `/api/profiles` | 获取所有角色配置 |
| POST | `/api/profiles` | 创建新角色 |
| PUT | `/api/profiles/{id}` | 更新角色配置 |
| DELETE | `/api/profiles/{id}` | 删除角色 |

#### 6.2 WebSocket 协议

**客户端 → 服务端**

```json
// 发送聊天消息
{"type": "chat", "profile_id": "assistant", "content": "你好", "id": "msg_001"}

// 切换活跃角色
{"type": "switch_profile", "profile_id": "writer"}

// 心跳保活
{"type": "ping"}

// 请求角色状态
{"type": "get_status"}

// 启动真实 AI 引擎
{"type": "start_profile", "profile_id": "coder"}
```

**服务端 → 客户端**

```json
// 角色状态更新
{"type": "status", "profiles": [{"id": "assistant", "name": "AI Assistant", "online": true}]}

// AI 回复
{"type": "chat", "profile_id": "assistant", "content": "你好！有什么可以帮助你的？", "id": "msg_001"}

// 心跳响应
{"type": "pong"}

// 错误信息
{"type": "error", "message": "Profile not found", "code": "PROFILE_NOT_FOUND"}
```

### 7. 常见问题与故障排除

#### 7.1 连接失败

**症状**：客户端显示「未连接」

**解决方法**：

1. 检查服务端是否已启动：`curl http://<服务器IP>:8080/health`
2. 检查防火墙是否开放端口
3. 确认 WebSocket 地址格式正确（`ws://<IP>:<端口>/ws`）
4. 查看服务端日志：`tail -f /tmp/server*.log`

#### 7.2 AI 无响应

**症状**：消息已发送但未收到回复

**解决方法**：

1. 等待角色初始化完成（首次对话需要 10-60 秒加载真实 AI）
2. 检查角色状态是否为「工作中」而非「启动中」
3. 重新发送消息
4. 重启服务端

#### 7.3 网络断开重连

1Claw 客户端内置自动重连机制：
- 第 1 阶段：每 10 秒重连一次，最多 30 次
- 第 2 阶段：每 60 秒重连一次，最多 30 次
- 两阶段均耗尽后，提示用户手动重连

### 8. 安全说明

- 通信加密：客户端与服务端通过 WebSocket（可启用 WSS）进行通信
- 会话隔离：每个智能体角色的会话数据和记忆相互隔离
- 本地存储：用户服务器配置信息存储在客户端本地
- API 密钥安全：AI API 密钥存储在服务端环境变量中，不传输到客户端
