## 软件功能与特点

### 软件主要功能

1. **多智能体同时在线**：同时加载多个 AI 智能体角色，每个角色独立运行、独立会话、独立记忆
2. **WebSocket 实时通信**：通过 WebSocket 长连接实现毫秒级实时双向消息传输
3. **跨平台客户端**：Flutter 开发，支持 Android/iOS/macOS/Windows/Linux
4. **Metro 风格 UI**：卡片式角色列表，支持搜索、排序、状态实时更新
5. **角色管理**：创建、编辑、删除智能体角色，配置名称、头像、描述、颜色
6. **智能体懒加载**：双阶段初始化策略，5 秒内快速上线，按需加载真实 AI 引擎
7. **断线自动重连**：两阶段重连策略（10秒间隔×30次 + 60秒间隔×30次）
8. **后台保活**：Android 前台服务保障后台连接持续运行
9. **系统通知**：收到 AI 回复时通过系统通知栏推送消息
10. **多主题支持**：浅色/深色双主题模式
11. **字体自定义**：支持选择系统已安装字体作为界面显示字体
12. **健康检查**：服务端提供 HTTP 健康检查端点
13. **REST API**：提供完整的角色管理 RESTful 接口
14. **会话持久化**：SQLite 存储聊天记录，支持多设备同步

### 软件技术特点

1. **Go 语言服务端**：高性能、低内存占用（运行内存 ≤ 500MB）
2. **Flutter 跨平台客户端**：一套代码覆盖 5 个平台
3. **Provider 状态管理**：响应式 UI 架构，实时反映连接状态变化
4. **JSON-over-stdin/stdout 进程间通信**：服务端通过子进程方式与 Python AI 引擎通信
5. **模块化设计**：WebSocket Hub、Agent Bridge、REST API、数据存储各模块职责清晰

## 主要算法

1. **两阶段 WebSocket 重连算法**：按递增间隔逐步增加重连尝试时间，第一阶段10秒/次30次，第二阶段60秒/次30次，超出则提示手动重连
2. **双阶段智能体初始化算法**：首次启动用 Echo 模式即时上线，用户首次交互时后台异步加载真实 AI 引擎
3. **消息路由算法**：基于 Profile ID 的哈希路由，将 WebSocket 消息分发到对应智能体子进程
4. **心跳保活算法**：30秒间隔发送 Ping 消息，60秒超时判定断线
